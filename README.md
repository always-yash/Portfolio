# Yash Choudhary | Systems Designer & Engineer

My personal portfolio is a motion-rich space for exploring the work, ideas, and systems I build at the intersection of design and engineering.

The experience is intentionally more than a collection of project links. It is a small, expressive interface system: responsive layouts, carefully paced animation, interactive project cards, theme persistence, and a visual language that reflects how I like to work. Every detail is built to feel considered while remaining fast, accessible, and easy to navigate.

## What I Do

I design and engineer digital experiences that balance visual clarity with technical depth. My work spans:

- UI/UX design and design systems
- Responsive, pixel-focused web interfaces
- Motion design and interaction direction
- React and modern front-end development
- Salesforce administration, development, and Lightning architecture
- Apex, SOQL, Flow, Agentforce, and CRM integrations
- Performance tuning, UI architecture, and full-stack system thinking

## What I Use

### Front end

- Semantic HTML5
- Modern CSS with custom properties, responsive layouts, and light/dark themes
- Vanilla JavaScript for interaction logic
- React, Next.js, TypeScript, and Bootstrap across broader projects

### Design and motion

- Figma, Relume, and Webflow for interface exploration and prototyping
- GSAP and ScrollTrigger for scroll-based animation and staged reveals
- Lenis for smooth scrolling
- SplitType for animated typography
- VanillaTilt for tactile visual interaction
- Swiper for the project carousel

### Salesforce and systems

- Salesforce CRM, Admin, Developer, and Lightning platform tools
- Apex, SOQL, Flow, Agentforce, and Headless 360
- Linux and Windows environments
- Networking, custom ROMs, rooting, and performance optimization

## Portfolio Features

- Responsive layout designed for desktop and mobile screens
- Smooth anchor navigation with active section tracking
- Light and dark themes saved with `localStorage`
- Reduced-motion support for users who prefer less animation
- Interactive magnetic buttons, cursor glow, tilt effects, and ripple feedback
- Animated hero typography and scroll-triggered section reveals
- Autoplaying, draggable project carousel with GitHub links
- Project data separated from presentation for straightforward updates
- Accessible navigation labels and descriptive image alternative text
