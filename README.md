# Yash Choudhary - Developer Portfolio

Modern personal portfolio for Yash Choudhary, built with vanilla HTML, CSS, and JavaScript.

## Structure

```text
Portfolio/
├── index.html
├── css/
│   ├── style.css
│   └── animations.css
├── js/
│   ├── app.js
│   ├── theme.js
│   └── projects.js
├── Assets/
│   ├── Hero-Preview-Desktop.png
│   └── Hero-Preview-Mobile.png
└── README.md
```

## Notes

- `app.js` handles navigation, motion, and general interactions.
- `projects.js` owns the project carousel, filters, and modal case studies.
- `theme.js` persists the light and dark theme toggle.
